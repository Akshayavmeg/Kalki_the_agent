"""""""""""""""""""""""""
import sounddevice as sd
from scipy.io.wavfile import write
from faster_whisper import WhisperModel
duration = 5
sample_rate = 16000
print("Speak now...")
audio = sd.rec(
    int(duration * sample_rate),
    samplerate=sample_rate,
    channels=1,
    dtype="int16"
)
sd.wait()
write("recording.wav", sample_rate, audio)
print("Loading model...")
model = WhisperModel("base")
print("Transcribing...")
segments, info = model.transcribe("recording.wav")
for segment in segments:
    print(segment.text)""""""""""""""""""""""
sounddevice → records audio from your microphone.
write from scipy → saves audio as a .wav file.
WhisperModel → converts speech into text.
duration = 5 → record for 5 seconds.
sample_rate = 16000 → 16,000 audio samples per second (good for speech recognition).
5 * 16000 = 80000
Records 80,000 audio samples from the microphone.
Parameters:
channels=1 → mono audio.
dtype="int16" → standard WAV format.
sd.wait()
Wait for recording to finish
write("recording.wav", sample_rate, audio) means save the audio into recording.wav file

"model = WhisperModel("base")" : means it does not store what you spoke.It creates and loads the Whisper AI model into the variable model.
*Load the Whisper "base" speech recognition brain
and store it in the variable named model.
"segments, info = model.transcribe("recording.wav")" : Now the model listens to recording.wav and converts it to text. 


What stores your speech?

Your speech is first stored in:

audio = sd.rec(...)

Then saved as:

recording.wav

Then Whisper converts it:

segments, info = model.transcribe("recording.wav")

The recognized text is stored in segments.
